## 2025-04-16 - Prevent Man-in-the-Middle (MitM) attacks by enforcing strict TLS verification in Puppeteer
**Vulnerability:** The Puppeteer browser launch configuration for production environments included `ignoreHTTPSErrors: true`.
**Learning:** `ignoreHTTPSErrors: true` forces Puppeteer to blindly accept all TLS/SSL certificates, including self-signed, expired, or actively malicious certificates. This entirely defeats the purpose of HTTPS and exposes the application to Man-in-the-Middle (MitM) attacks, where an attacker could intercept, read, or modify data being scraped (like financial data) or credentials sent from the application to external services. While it is sometimes used as a hack to bypass certificate issues in development, it must never be deployed to production.
**Prevention:** Remove `ignoreHTTPSErrors: true` from production deployment configurations and ensure that external services are properly serving valid, trusted SSL/TLS certificates. If specific internal servers use self-signed certificates, the server's certificate should be trusted at the OS level instead of disabling certificate validation globally.

## 2025-05-02 - Mitigate Indirect Prompt Injection in LLM Prompts
**Vulnerability:** External scraped data (news context) was being passed directly into the LLM prompt without any boundary definitions. This created an Indirect Prompt Injection vulnerability, where an attacker could embed malicious instructions in external news articles, which the LLM might interpret as commands rather than data.
**Learning:** When passing untrusted external data to LLMs, it is crucial to establish clear boundaries separating system instructions from external data. Without these boundaries, the LLM cannot distinguish between commands it should follow and data it should analyze.
**Prevention:** Encapsulate untrusted content within specific XML tags (e.g., `<noticias_externas>`) and pair this with explicit system prompt instructions directing the LLM to strictly ignore any commands or directives found within those tags, treating the contents purely as data.
